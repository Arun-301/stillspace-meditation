STILLSPACE WEBSITE
1. Extract the ZIP.
2. Open the Stillspace folder in VS Code.
3. Open index.html in a browser, or use VS Code Live Server.
4. Add your own audio files in music/:
   - meditation.mp3 (background music)
   - bell.mp3 (completion bell; plays for 12 seconds)
The website works without audio files, but music and bell sounds need those files.
Features: responsive meditation dashboard, 3 breathing patterns, orb phase/countdown, timer controls, local history, streaks, daily goal and JSON export.
Progress is stored in browser localStorage.
