# Stillspace 🌿

A simple meditation and breathing website built to help people slow down, relax, and take a break from their busy lives.

## About the Project

Stillspace is a personal web development project focused on making meditation easier to practice. It provides guided breathing exercises with a visual breathing orb, background meditation music, and a way to track daily progress.

I wanted to build something with a clean design that feels calm and is easy to use, without unnecessary distractions.

## Features

- Three breathing exercises: Relaxation, Simple Breathing, and Box Breathing.
- Animated breathing orb that follows each breathing phase.
- Session timer with pause and resume options.
- Background meditation music and a completion bell.
- Track completed sessions and daily streaks.
- Set daily meditation goals.
- Save progress in the browser.
- Export meditation history as a JSON file.
- Responsive layout for desktop and mobile screens.

## Technologies Used

- HTML
- CSS
- JavaScript
- LocalStorage
- HTML Audio API

## Getting Started

1. Clone this repository:

   ```bash
   git clone https://github.com/YOUR-USERNAME/stillspace.git
   ```

2. Open the project folder in VS Code.

3. Add your audio files to the `music` folder:
   - `meditation.mp3`
   - `bell.mp3`

4. Open `index.html` in your browser or run it using the Live Server extension in VS Code.

Replace `YOUR-USERNAME` with your GitHub username.
